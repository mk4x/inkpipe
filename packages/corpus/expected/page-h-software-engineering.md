# Software Engineering

## Requirements

Properties of requirements:

- Validity (real want?)
- Consistency (harmony with other reqs?)
- Completeness (fully described?)
- Realism (achievable?)
- Verifiability (testable?)

## Functional / Non functional req

- What can it do
- How well / under what constraints does it do it

| Func examples | Non-func |
| --- | --- |
| User auth | Performance: 10000 queries in 5 sec |
| Search functionality | Security |
| Payment | Usability |

Stakeholders = affected by system and interested

## Prioritization

- Numerical or weighted scoring
- MoSCoW method (must have, should have ...)
- Kano Model (user centered model)
- ICE model (impact, confidence, ease)
